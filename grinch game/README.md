# Grinch Game (working title)

A Roblox stealth heist game: play as a grumpy, holiday-hating creature who sneaks
into a gated holiday neighborhood on Christmas Eve to steal presents without
getting caught.

> Note: the final game will use an original character, dog, and town name
> (not the copyrighted Grinch / Max / Whoville) so it can be published on Roblox.

## Core loop
1. Fly your homemade, patched-together sleigh (pulled by your loyal scruffy dog) to a house.
2. Sneak in through chimneys or windows.
3. Grab presents, stockings, decorations, and trees — stuff them in your sack (heavier sack = slower).
4. Escape back to the sleigh and haul the loot to your mountain lair.
5. Spend loot on upgrades, then hit tougher houses.

## Threats
- **Security cameras** — sweeping view cones
- **Laser tripwires** — set off alarms
- **Parents** — patrol and investigate noises
- **Kids** — wake up, wander, and yell for parents
- **Police** — show up when the alert level gets too high

## Upgrades (ideas)
- Bigger sack / more carry weight
- Quieter sneaking suit
- Camera jammer
- Decoy toy to distract kids
- Grappling hook
- Smoke puff escape
- Faster dog / bigger sleigh

## Tech
- Built in Roblox Studio with Luau
- DataStore to save loot and upgrades between sessions
